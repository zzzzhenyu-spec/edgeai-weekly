# 端侧大模型知识分享 · Demo（思维导图版）

以**思维导图**形式展示端侧大模型基础知识：左侧主干「端侧大模型」→ 三条领域分支（基础概念/青 · 压缩量化/紫 · 推理与硬件/橙）→ 概念叶子卡（两列网格）。每个概念带一句话白话解释与带圈数字「建议阅读顺序」，点击在右侧抽屉展开详解。**全部内容数据驱动，加新技术零代码改动。**

- 双击 `index.html` 即可打开（`file://` 可用，无任何外部依赖、无网络请求）
- 配色与光晕气质延续「端侧AI每周情报站」，布局独立设计（2026-10-30 三轮定稿：分区列 → 居中排版 → 思维导图）
- 定位：**独立 Demo**。后续开新项目时，本目录整体拎走即成项目骨架

## 怎么加内容（全部只改 `kmap_data.js`）

### 1. 加一个新概念（比如"投机解码"）

在 `nodes` 里复制一个对象改字段：

```js
{
  id: "spec-decode",            // 唯一短 id（hash 深链 #node/spec-decode 也用它）
  domain: "runtime",            // 所属领域 id
  title: "投机解码",
  en: "Speculative Decoding",
  level: "进阶",                 // 只有两档："入门" | "进阶"
  path: 9,                      // 可选：新手路线第几站（不填 = 不在路线中）
  oneLiner: "小模型先打草稿、大模型只负责验收——生成快了，答案不变味",
  detail: ["……", "……"],        // 2–3 段白话详解，关键数字带单位
  keys: ["加速 2–3 倍常见", "……"],
  related: [                     // 连线：lead=实线箭头(前置) / rel=虚线(相关)
    { to: "tps",  kind: "rel", note: "直接提升 decode 的 token/s" },
    { to: "quant", kind: "rel", note: "草稿模型也用量化版" }
  ],
  refs: [ { name: "Fast Inference (arXiv:2211.17192)", url: "https://arxiv.org/abs/2211.17192" } ]
}
```

保存刷新即可：卡片自动进入对应领域列、连线自动计算绘制、搜索与筛选自动收录、统计数字自动更新。**不需要碰任何布局代码、不需要写坐标。**

### 2. 加一个新领域（比如"多模态与安全"）

在 `domains` 里加一条 `{ id, name, icon, accent, desc }`——地图自动多出一列（列宽自适应，超出屏宽可横向滚动）。

### 3. 连线规则（v8 定稿）

- **主干 → 分支节点**：每分支 1 条 S 曲线（dx 严格 < 间距一半，不会打回钩）
- **分支 → 概念卡：每分支只画首、末两条扇形曲线**（中间卡不画线）——加多少张卡，线条数都不变，导图永远清爽
- **跨领域关联**写在节点 `related` 里（`lead` 前置 / `rel` 相关），默认隐藏，悬停节点点亮
- 连线坐标运行时按布局位置计算（offsetParent 链累加，几何断言端点 0px 贴边），节点增删、收起、筛选、换屏都不断线
- **知识一览**＝建议阅读顺序：带圈数字常显，点开关触发 ①→⑩ 逐个弹跳

### 4. 公共知识区（网络好分享）

加一条 = 在 `shares` 数组追加 `{ name, desc, url, tag }`（tag 建议：视频/课程/路线图/工具/报告/博客），自动渲染成链接卡；`url` 仅接受 http(s)。

### 5. 内容写作约定（与周报站知识板块一致）

- 通俗优先：先直觉与类比，再上术语；术语首次出现给一句白话解释，术语用「」引用
- 关键数字一律「数字 + 单位」（`14GB`、`10+ token/s`、`约 1/4`）
- 延伸阅读优先 arXiv abs 页 / 官方文档；`url` 仅接受 http(s)
- `path` 序号建议按分支成块编（基础①②③④→量化⑤⑥→…），避免顺序链频繁跨分支跳跃

## 交互一览

| 操作 | 效果 |
|------|------|
| 点击概念卡 | 右侧抽屉展开：一句话 → 详解 → 关键数字 → 关联概念（可点击跳转）→ 延伸阅读 |
| 点击分支节点 | 收起 / 展开该分支的概念卡（▾ 指示） |
| 悬停卡片 | 点亮它的跨领域关联线与邻居卡，无关节点压暗 |
| 搜索框（顶栏） | 按标题 / 术语 / 一句话 / 关键数字实时过滤（分支计数联动） |
| 难度 chips | 入门 / 进阶筛选（计数显示在 chip 上） |
| 知识一览开关 | ①→⑩ 徽章按步弹跳点亮，其余压暗 |
| `#node/<id>` | 深链直开某概念详情（关闭抽屉自动清 hash） |
| Esc / 遮罩 / ✕ | 关闭抽屉 |
| 公共知识区 | 地图下方的外链卡片，新窗口打开 |

**发布提示**：改完源目录（`D:\Code\edge-llm-map-demo`）后，①同步副本到周报库 `map/`；②`index.html` 里三个 `?v=N` 版本参数**递增**（绕过 GitHub Pages 10 分钟缓存）；③commit 后跑 `python scripts/publish_public.py`。

## 设计决策（为什么是思维导图，不是力导向图谱）

- 2026-10-30 三轮演进定稿：分区列 → 居中排版 → **思维导图**（用户拍板：配色光学周报站，布局独立）
- 思维导图的层级（主干→分支→叶子）天然承载"从属关系"，叶子两列网格让 40+ 概念仍可同屏纵览；加概念=枝上长叶、加领域=多一条枝，纵向扩展永远成立
- 力导向图谱节点一多就糊、每次加节点布局漂移，违背"好扩展"首要目标
- 阅读顺序用"带圈数字常显 + 一览开关"表达，比隐藏的路线图更直白
